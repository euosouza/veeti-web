Tipos e Hierarquia

Utilize diferentes estilos para indicar a importância das ações na interface.

Botão Primário

Primário

Para a ação principal da tela. Deve haver apenas um botão primário por seção ou view.

Botão Secundário

Secundário

Para ações secundárias ou complementares à ação primária.

Botão Destrutivo

Destrutivo

Para ações destrutivas, como excluir ou remover conteúdo.

Botão Outline

Outline

Para ações alternativas ou secundárias, como "Cancelar" ou "Voltar".

Botão Link

Link

Para ações de baixa prioridade ou links dentro de componentes.

Ícone

Usado em toolbars ou espaços compactos onde o ícone comunica claramente a ação.
